          ORDS HTTP(S)
          
Use your existing Oracle database username and password through ORDS. No separate ORDS account is needed. The schema must be REST-enabled and permit REST-enabled SQL.

          
Use the schema URL provided by your administrator. Its schema alias can differ from your database username.

          
Leave the password blank to keep it for the same URL and database username. A changed URL or username requires a password.

          
SQLcl cannot save ORDS connections. APEXREST stores these settings and the database password locally at plugin level.

          
Configure ORDS from the CLI
Provide your database password through a local file:
apexrest connection add --name REF --ords-url https://example.com/ords/schema-alias/ --ords-username DATABASE_USER --password-file PATH
Interactive SQLcl example:
connect -orest DATABASE_USER@https://example.com/ords/schema-alias/
