# Customer CRM starter

`project init ./crm --template customer-crm` generates fresh Oracle application metadata and applies the CRM overlay with customer migrations and PL/SQL validation. Configure the exact environment and authorize its application/schema changes before deployment.

Verify login, invalid input, create, read, update, search and delete through the host in-app browser using a dedicated test account and disposable synthetic data. The starter contains no automated application tests or browser dependencies.
