# Інтеграція з Codex

[English](codex-integration.md) | Українська

APEXREST призначений для Codex desktop і CLI. Бета 1.3.0-beta.1 містить 14 спеціалізованих skills і 21 MCP-інструмент з обмеженим виводом, включно з експериментальним скілом [Composer](composer.uk.md); стабільна 1.2.0 містить 13 skills і 18 MCP-інструментів, включно зі [скілом каталогу патернів](pattern-catalog.uk.md). Стан публікації — у [примітках до випуску](release-notes.uk.md). Codex виконує завдання користувача у відкритій розмові; APEXREST надає детерміновані операції Oracle/APEX через локальний stdio MCP та відповідний CLI.

## Розподіл відповідальності

- Codex керує розмовою, моделлю, дозволами й власною співпрацею.
- APEXREST керує конфігурацією проєкту, зафіксованою довідкою, адаптерами Oracle, політикою розгортання, виконанням тестів і відновлюваними завданнями операцій.
- Необов’язкова панель розробки показує налаштування проєкту/з’єднань і операції Oracle/APEX. Відкривайте її приватну локальну URL у вбудованому браузері Codex; налаштування браузера перевірки окремо застосовується до перевірок застосунку.

APEXREST не запускає сесії моделей Codex, не обирає моделі й не підтримує паралельний контекст розмови. API запуску роботи плагіна немає. Для реалізації використовуйте [скіл поточного чату](chat-workflow.uk.md), а предметні інструменти викликайте, коли потрібна фактична операція.

## Межі хоста та перевірки

Нативний маніфест оголошує skills і MCP-ресурси. Локальна панель і її MCP UI ресурс — окремі інтерфейси: коректний ресурс або повернена URL не доводять відображення хостом. Браузерні спостереження, CLI/stdio-перевірки встановленого плагіна й реальні операції Oracle записуються окремо.

[Історичні докази 1.0.0](evidence/current-session-100-local.json) зберігають перевірки своїх джерел; [докази каталогу 1.1.0](evidence/component-catalog-local.json) фіксують поточний корпус компонентів. Попередні звіти нативного хоста зберігають свої версії хоста, хеші джерел і межі; вони не перевіряють відображення цього випуску в desktop. Дивіться [стан реалізації](implementation-status.uk.md) та [відкриті перевірки](next-actions.uk.md).

Початкова [специфікація збірки](../APEXREST_CODEX_PLUGIN_BUILD_SPEC.md) збережена як історичні вхідні дані. Вона не є поточним контрактом продукту; [матриця приймання](acceptance.json) фіксує актуальний обсяг і замінені вимоги.
