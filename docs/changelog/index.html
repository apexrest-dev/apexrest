    2.5.0

    • Push live updates to local preview pages over a WebSocket (<app>/__apex/live). Writes to local tables refresh the regions that read them in every tab and session. .apx edits reload open pages, and parse errors appear on the page. The toolbar's Live button shows presence. Grids with unsaved edits and forms are never refreshed, and refresh loops are prevented. Connected mode pushes only source reloads.

    • Check preview properties against the component type the compiler uses. Report columns, dynamic action actions, display conditions, grid column settings, required slots and sequences are now checked. The generated showcase application had 173 distinct compiler errors and no preview warnings; preview check now reports 161 of them. Oracle's 1,350 public sample pages still produce no findings.

    • Make CLI previews discoverable and stoppable across processes: preview status|stop accept --project, --source-dir and --port. A stop that stops nothing reports PREVIEW_NOT_RUNNING. Add apex validate --source-dir, per-command --help and bare boolean flags, and remove the unsupported sandbox stub.

    • Refuse production-marked environments before any connection or SQLcl call in plan, apply and restore. Report a missing SQLcl saved connection as SQLCL_CONNECTION_NOT_FOUND. Keep component recipes and patterns in reference searches scoped by a project. Explain composer compiler mismatches with the matching blueprints. Warm up connected previews before the URL is returned.

    • Replace the repository's feature videos with the seven-episode YouTube series "Oracle APEX with AI agents". The features page lists every episode with its thumbnail and links each feature to its episode. The old MP4, caption and poster files are removed from docs/assets.

    • Fix local preview chart text in dark theme styles, the grid Color editor rewriting values that were not edited, a grid null error after a save, and toolbar times (now local) and counts (now pluralized). Truncated compiler reports now say where the full diagnostic list is.

    • Add productionDatabases to $APEXREST_HOME/production-trust.json: listing a DB_UNIQUE_NAME makes every service name, workspace, schema and application on that database production, so a production mark no longer depends on the service name or application ID a project configures.

    • Bind peer reviews to the real plan: the saved plan must match its digest and pass apply's local checks before the reviewer runs, required mode refuses and ignores reviews by the host agent's own vendor, and the agent's focus text is fenced as an untrusted request in the reviewer prompt.

    • Give SQLcl write sessions (imports, migrations, packages, restores) up to 60 minutes instead of the 3-minute read limit, and do not recover or re-import automatically after APEXREST stopped SQLcl on a timeout, cancellation, output limit or unconfirmed batch: the server may still be executing the call. Lost responses and Oracle errors keep the server-first automatic recovery.

    • Run dynamic action server code in the local preview only as the application defines it. Rendering a page registers each Execute Server-side Code and SQL/PL/SQL Set Value action in the session; the browser sends only its reference, and the routes ignore any code, SQL or type in the request. Only the declared Items to Submit are set and only the declared Items to Return come back. The registered code is the source as written, without &ITEM. substitution, as in APEX. Previously the preview executed whatever code a request contained.

    • Read comments, string literals, q-quotes and quoted identifiers in one pass, as Oracle does, before checking connected preview code for COMMIT, ROLLBACK, EXECUTE IMMEDIATE, DBMS_SQL and autonomous transactions. Previously a q'[ inside a comment hid a following COMMIT; code with an unclosed literal or comment is now refused.

    • Keep APEX built-ins such as APP_USER, APP_ID, APP_SESSION, APP_PAGE_ID and REQUEST out of reach of session state in the local preview: URL parameters with those names are ignored with a warning, and binds, &NAME. substitutions, the PL/SQL interpreter, v(), nv() and apex_util.get_session_state always return the engine value. Previously ?app_user=ADMIN changed :APP_USER in every query, condition and authorization check, also in connected mode.

    • Stop connected preview code from leaving its SQLcl block: page code and region SQL with a line SQLcl acts on regardless of quoting (only /, only ., a leading #, or in SQL a line ending with ;) are refused before anything is sent, and bind values reach the script without raw line breaks. Previously such code could end its begin…end; early and run DDL, which commits.

    • Refuse local preview requests that another web page could send: a Host other than the preview's loopback address and port, an unsafe method with a foreign or null Origin, and cross-site or same-site requests other than top-level GET navigations. Previously any page in the browser could post SQL or PL/SQL to the preview, which in connected mode runs against the DEV/QA/TEST database.

    • Require a per-run completion marker after every migration and package script. A script whose output lacks it (an early exit, or a client command such as ACCEPT that consumes the remaining input) leaves the migration started with an unknown outcome instead of recording it as succeeded or applied.

    • Give the local preview Oracle data semantics: empty items bind as NULL, real division, Oracle number text, date arithmetic on any date expression, ANSI date literals and DEFAULT sysdate in seeds, json_value/json_query/json_exists, nested LISTAGG, POSIX regular expressions and ISO date storage for form DML.

    • Run page submits, server-side code and grid saves in one transaction: unhandled process errors stop processing, are shown to the user and roll back. Add interactive grid row validations, #LABEL#/#COLUMN_HEADER# substitution, lost-update detection, region items to submit on refresh, clearCache lists and synchronous Cancel Event.

    • Render 26.2 report and card syntax: show-all pagination, card actions, &COLUMN. substitution, list view features, calendar views, template directives in HTML expressions, template component format masks, FILESIZE/SINCE_SHORT masks, interactive report aliases and integer chart ticks.

    • Fix switch styling, floating labels, grid column offsets and label spans, native date pickers, button static IDs, the region display selector, and map height, row assignment, styles, heat maps and info windows. Warn about unknown APEXlang properties and values; Oracle's 1,350 public sample pages produce no findings.

    • Rewrite the README around the Codex and Claude Code plugin and its three feature videos, adding a tour of the local preview on a 22-page showcase application. Align package and Codex/Claude Code source versions to 2.5.0; registry publication remains a separate outcome.

    2.4.0

    • Add a database-free local APEXlang preview: apexrest preview setup|start|check|stop|status and the apexrest_preview MCP tool, bringing the catalog to eleven tools with six skills.
    • Download the official APEX 26.2 distribution once, extract only its browser runtime and evaluate the Universal Theme export into templates; render pages with genuine 26.2 templates and JavaScript.
    • Cover most APEX UI/UX locally through feature modules: interactive reports and grids with editing and save, faceted search and smart filters, cards, Universal Theme template components and directives, tabs/carousel/region display selector/inline dialogs, SVG charts, FullCalendar calendars, offline maps, genuine page item widgets (date picker, popup LOV, combobox, shuttle and more), a PL/SQL subset interpreter for processes, validations, conditions and computations, and a wider dynamic action runtime.
    • Add interactive report Actions-menu views and saved reports, richer grid editors, tree regions with connect by, search regions, wizards and legacy regions, file uploads, BLOBs and data loading, apex_collection, generated APEX dictionary views, a local e-mail outbox, REST fixtures, and a developer toolbar with session state, debug log, view-as roles and viewport switching.
    • Implement the wwv_flow.accept submit protocol and SQLite data with Oracle SQL shims, .apex-local/*.sql seeding and on-demand sample tables. Unsupported features are reported as diagnostics; the preview is not compiler, import or Oracle evidence.
    • Keep the 2.3.0 optional OpenAI Decisions component selection unchanged. Align package and Codex/Claude Code source versions to 2.4.0; registry publication remains a separate outcome.

    See release notes, implementation status and open verification.
