# Evidence and release gates

English | [Українська](qualification.uk.md)

The ledger tracks all CMP-000–041 tasks, but local implementation is not complete. Consult the [audit](audit.md) for remaining local requirements; they are separate from deferred live acceptance. Baseline HEAD and existing dirty-work snapshots are private; the historical build specification is unchanged.

The local report records actual checks, real SQLcl offline compiler outputs, fixtures, source digests, package integrity, relocated CLI/MCP/panel parity and installation evidence. Schema/unit/compiler/source/import/browser/authorization/upgrade/packaging evidence are separate dimensions. Compiler output is not PL/SQL compilation in a live Oracle schema, an import, successful DML or role/browser acceptance. New blocks remain experimental/local-verified.

G4 requires separately authorized exact DEV metadata, fixture DDL/DML, application-only import and authenticated browser qualification, including null/invalid input, create/edit/cancel, stale version, denied roles, two instances, refresh/coalescing and narrow screens. None is silently marked passed. Linux/Windows CI and fresh-chat native tool discovery are recorded separately from macOS local checks and installed payload verification.

Benchmarks report local wall time, payload bytes, deterministic cache behavior and judged EN/UK retrieval. They are not native agent reasoning, paid-token or billing measurements. Publication/tagging/production rollout require a new explicit request. The protected release-readiness checker includes Composer runtime/native evidence and remains blocked while required evidence is missing.
